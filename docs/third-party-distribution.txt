Replacing LGPL libraries
------------------------
Close Cast to TV completely, including its tray icon, before replacing files.
Back up third-party/runtime. Extract the relevant source archive into a working
directory outside this distribution and make your changes there. Install Python
matching the manifest's version, ABI and Windows architecture (64-bit CPython
3.13 for this release). No application source or application rebuild is needed.

pystray: its source package lives under lib/pystray in the GitHub archive.
Replace third-party/runtime/pystray with that complete package, preserving
its interface. Its Pillow and six dependencies are supplied by the executable.

zeroconf: use its supplied pyproject.toml and build files. With a matching
Python, run `python -m pip wheel --no-deps --wheel-dir wheels SOURCE_DIRECTORY`.
This may download upstream build tools and may require the Visual Studio C++
Build Tools for compiled extensions. Extract the resulting wheel as a ZIP and
replace the whole third-party/runtime/zeroconf package and its dist-info folder.
Its ifaddr dependency is supplied by the executable. To edit the Python files
directly, remove the corresponding .pyd files so they do not override .py files;
zeroconf includes Python implementations. Preserve all package files and keep
your replacement compatible with the calling interfaces and runtime ABI.

Run `CastToTV.exe --check-runtime report.json` to produce an import report
without opening a GUI or connecting to a receiver. Reported paths should be
under third-party/runtime. Replacement libraries are not subject to application
version or checksum restrictions. The release validation tool checks original
release materials for distributors only; it is not a runtime restriction.
If a replacement fails, restore the backup or the complete original folder.
This permission does not require the distributor to support modified versions.
